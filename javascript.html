01 · MEANING

JavaScript는 무엇을 하나요?

HTML과 CSS만으로도 페이지를 보여줄 수 있지만, 사용자의 행동에 반응하려면 JavaScript가 필요합니다. 버튼을 누르면 글자가 바뀌거나 메뉴가 열리는 기능이 대표적인 예입니다.

JavaScript 파일도 HTML에 연결해야 실행됩니다. 두 파일을 같은 폴더에 만들고 </body> 바로 앞에 <script></script> 태그를 작성하세요.

my-page/
├─ index.html
└─ script.js
index.html
  <script src="script.js"></script>
</body>
scriptJavaScript 연결 태그

HTML에서 JavaScript 파일을 불러옵니다.

src="script.js"파일 위치 지정

같은 폴더에 있는 script.js 파일을 찾습니다.

</body> 앞HTML을 읽은 다음 실행

버튼과 제목이 만들어진 뒤 JavaScript가 요소를 찾도록 합니다.

연결이 되지 않을 때

03 · SYNTAX

JavaScript 코드의 기호를 읽어봅시다.

처음에는 모든 문법을 외우기보다 각 기호가 어떤 역할을 하는지 이해하는 것이 중요합니다.

script.js
// 화면에 보여줄 문장을 저장합니다.
const message = "안녕하세요";

console.log(message);
//주석

코드에 설명을 적습니다. 실행 결과에는 영향을 주지 않습니다.

const변수 선언

값을 기억할 이름을 새로 만듭니다.

=값 저장

오른쪽 값을 왼쪽 이름에 저장합니다.

"안녕하세요"문자열

글자는 따옴표로 감싸서 작성합니다.

( )함수에 값 전달

실행할 명령에 필요한 값을 넣는 자리입니다.

;명령 종료

한 줄의 명령이 끝났음을 표시합니다.

04 · VARIABLE

변수는 값을 기억하는 이름표입니다.

자주 사용하거나 나중에 다시 사용할 값을 변수에 저장합니다. 이름은 값의 의미를 알 수 있도록 작성하는 것이 좋습니다.

값을 다시 바꾸지 않을 때
const userName = "홍길동";

const는 처음 저장한 값을 다른 값으로 다시 바꾸지 않을 때 사용합니다.

값이 변할 수 있을 때
let count = 0;
count = 1;

let은 점수나 횟수처럼 실행 중에 값이 달라질 때 사용합니다.

변수 이름 작성 규칙

공백 대신 userName처럼 두 번째 단어의 첫 글자를 대문자로 작성합니다. 숫자로 시작하거나 const 같은 문법 이름을 변수명으로 사용할 수 없습니다.

05 · VALUE TYPE

JavaScript가 다루는 값에는 종류가 있습니다.

초보 단계에서는 글자, 숫자, 참과 거짓 세 가지를 먼저 구분하면 됩니다. 글자에만 따옴표를 사용한다는 점을 기억하세요.

STRING · 문자열

"안녕하세요"

이름, 제목과 안내 문구 같은 글자입니다.

NUMBER · 숫자

25

나이, 점수와 횟수처럼 계산할 수 있는 값입니다.

BOOLEAN · 불리언

true / false

켜짐과 꺼짐처럼 참 또는 거짓을 나타냅니다.

"10" + "5" → "105"따옴표가 있으면 글자입니다.

문자열끼리 더하면 두 글자가 이어집니다.

10 + 5 → 15따옴표가 없으면 숫자입니다.

숫자끼리 더하면 계산 결과가 나옵니다.

06 · FIND ELEMENT

기능을 넣을 HTML 요소부터 찾습니다.

JavaScript가 버튼이나 제목을 바꾸려면 먼저 해당 요소를 선택해야 합니다. document.querySelector() 안에는 CSS 선택자를 작성합니다.

index.html
<button id="startButton">
  시작하기
</button>
script.js
const button = document.querySelector(
  "#startButton"
);
document

현재 브라우저에 열린 HTML 문서 전체를 뜻합니다.

querySelector

조건과 일치하는 첫 번째 HTML 요소를 찾습니다.

"#startButton"

id="startButton"인 요소를 선택합니다.

선택자가 일치해야 합니다

HTML의 id="startButton"과 JavaScript의 "#startButton" 철자가 다르면 버튼을 찾지 못합니다.

08 · CHANGE PAGE

찾은 요소의 내용과 모양을 바꿀 수 있습니다.

JavaScript는 HTML 글자를 바꾸거나 CSS 클래스를 추가할 수 있습니다. 점 뒤에 실행할 기능의 이름을 이어서 작성합니다.

글자 바꾸기
title.textContent = "반갑습니다!";

textContent는 요소 안의 글자를 새로운 문장으로 바꿉니다.

클래스 추가하기
card.classList.add("active");

HTML 요소에 active 클래스를 추가해 미리 만든 CSS 디자인을 적용합니다.

디자인은 CSS에 작성하세요

JavaScript에서는 클래스를 추가하거나 제거하고, 실제 색상과 크기는 CSS의 .active에 작성하면 코드를 관리하기 쉽습니다.

09 · CONDITION

조건에 따라 다른 결과를 실행할 수 있습니다.

if는 괄호 안의 조건이 참일 때 코드를 실행합니다. 조건이 거짓일 때는 else 안의 코드를 실행합니다.

script.js
const age = 20;

if (age >= 18) {
  console.log("입장할 수 있습니다.");
} else {
  console.log("입장할 수 없습니다.");
}
age >= 18조건 확인

age가 18 이상인지 비교합니다.

거짓이면 →
