01 · BEFORE INSTALLING

HTML 확장부터 찾을 필요는 없습니다.

VS Code는 HTML, CSS, JavaScript 편집 기능을 기본으로 제공합니다. HTML 태그 자동 완성과 Emmet도 이미 내장되어 있으므로 별도의 HTML 확장을 먼저 설치할 필요가 없습니다.

<>HTML

태그 추천, 자동 닫기와 코드 서식

#CSS

속성 추천, 색상 미리보기와 값 검사

JSJavaScript

코드 완성, 문법 정보와 오류 표시

!Emmet

! 입력 후 완성되는 HTML 기본 구조

02 · ESSENTIAL EXTENSIONS

미리보기 두 가지와 코드 정리 도구입니다.

추천 1번과 2번은 기능이 비슷하므로 둘 중 하나만 선택해도 됩니다. 아래 이름과 게시자, 확장 ID를 함께 확인하세요.

추천 01 · 편집기 미리보기

Live Preview

게시자 Microsoft · ID: ms-vscode.live-server

HTML 파일을 로컬 서버로 실행하고 VS Code 안의 미리보기 화면이나 외부 브라우저에서 확인합니다. 코드를 수정하면 미리보기 화면을 자동으로 새로고칠 수 있습니다.

사용 방법HTML 파일을 연 뒤 편집기 오른쪽 위의 미리보기 버튼을 누르거나 파일에서 마우스 오른쪽 버튼을 눌러 미리보기를 실행하세요.
확인 사항현재 공식 마켓에서는 시험판으로 안내하고 있습니다. 일반 VS Code에서 문제가 생긴다면 아래 Live Server를 대신 사용하세요.
공식 마켓 페이지 ↗
추천 02 · 외부 브라우저 미리보기

Live Server

게시자 Ritwick Dey · ID: ritwickdey.LiveServer

HTML 파일을 로컬 서버로 열고, 파일을 저장할 때 브라우저 화면을 자동으로 새로고침합니다. 수정 결과를 바로 확인하기 좋습니다.

사용 방법HTML 파일을 열고 아래 상태 표시줄의 Go Live를 누르세요.

추천 03 · 코드 정리

Prettier - Code formatter

게시자 Prettier · ID: esbenp.prettier-vscode

들여쓰기와 줄바꿈을 일정한 규칙에 맞게 자동으로 정리합니다. HTML, CSS와 JavaScript를 모두 지원합니다.

사용 방법Shift + Alt + F를 눌러 문서 전체를 정리하세요.
공식 마켓 페이지 ↗
Live Preview와 Live Server를 동시에 설치할 필요는 없습니다.

VS Code 안에서 바로 보고 싶다면 Live Preview를, 별도의 브라우저 창에서 단순하게 확인하고 싶다면 Live Server를 선택하세요. Prettier는 두 미리보기 확장과 역할이 다르므로 함께 사용할 수 있습니다.

03 · HOW TO INSTALL

확장 프로그램 설치는 네 단계입니다.

  1. 01
    확장 메뉴 열기

    VS Code 왼쪽의 블록 모양 아이콘을 누르거나 Ctrl + Shift + X를 누릅니다.

  2. 02
    정확한 이름 검색

    검색창에 Live Preview, Live Server 또는 Prettier - Code formatter를 입력합니다.

  3. 03
    게시자와 ID 확인

    이름만 보지 말고 위 카드에 적힌 게시자와 확장 ID가 같은지 확인합니다.

  4. 04
    Install 누르기

    설치가 끝나면 VS Code를 다시 시작할 필요 없이 대부분 바로 사용할 수 있습니다.

선택 설정 · settings.json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}

위 설정은 파일을 저장할 때마다 Prettier가 코드를 자동 정리하도록 합니다. 처음에는 직접 단축키로 사용해 본 뒤 필요할 때 적용해도 됩니다.
