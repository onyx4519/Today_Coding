02 · RULE

선택하고, 속성을 정합니다.

CSS 규칙은 “무엇을 꾸밀지” 선택한 뒤 중괄호 안에 “어떻게 꾸밀지” 적는 구조입니다.

.card {
  background: #171727;
  border-radius: 24px;
}
단위도 확인하세요

px는 화면의 크기를 나타내는 가장 기본적인 단위입니다.

03 · FIRST STYLE

첫 CSS 코드를 적용해 봅시다.

HTML의 class="card" 요소와 그 안의 제목, 문단, 버튼을 각각 꾸밉니다. 강조된 CSS 값을 수정한 뒤 결과가 어떻게 달라지는지 확인해 보세요.

styles.css 
.card {
  width: 100%;
  max-width: 420px;
  margin: 0 auto;
  padding: 32px;
  border: 1px solid #35354a;
  border-radius: 24px;
  background: #171727;
  box-shadow: 0 18px 45px rgba(23, 23, 39, 0.28);
  text-align: center;
}

.card h3 {
  margin: 0 0 10px;
  color: #f7f7fb;
  font-size: 28px;
}

.card p {
  margin: 0 0 20px;
  color: #b8b5c7;
  line-height: 1.7;
}

.card button {
  padding: 10px 18px;
  border: 0;
  border-radius: 8px;
  background: #7650e6;
  color: #ffffff;
  font-weight: 700;
  cursor: pointer;
  transition: transform 0.2s ease;
}

.card button:hover {
  transform: translateY(-2px);
}
