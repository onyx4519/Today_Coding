01 · FILE STRUCTURE

먼저 한 폴더 안에 파일을 모읍니다.

웹페이지에 필요한 HTML, CSS, JavaScript와 이미지 파일은 하나의 프로젝트 폴더 안에서 관리합니다. 파일 위치가 바뀌면 연결 주소도 함께 바뀐다는 점을 기억하세요.

my-first-site/
├─ index.html
├─ styles.css
├─ script.js
└─ images/
   └─ profile.jpg
index.html

페이지의 내용과 순서를 작성합니다.

styles.css

색상, 크기, 여백과 배치를 정합니다.

script.js

클릭이나 입력에 반응하는 기능을 만듭니다.

images/

사진과 그림 파일을 한곳에 모읍니다.

처음에는 파일명을 그대로 사용하세요.

영문 소문자와 하이픈을 사용하고 공백은 피하는 것이 좋습니다. 예: profile-image.jpg

02 · SCREEN STRUCTURE

화면을 역할이 다른 영역으로 나눕니다.

웹페이지는 보통 머리말, 메뉴, 핵심 내용, 여러 내용 구역과 바닥글로 구성됩니다. 각 영역의 역할을 먼저 정하면 어떤 태그를 사용해야 할지 쉽게 판단할 수 있습니다.

<header>사이트 이름과 첫인상
<nav>페이지 이동 메뉴
<main>현재 페이지의 핵심 내용
<section>첫 번째 주제
<section>두 번째 주제
<footer>만든 사람과 추가 정보
index.html
<body>
  <header>
    <h1>나의 첫 웹페이지</h1>
    <nav>
      <a href="#about">소개</a>
      <a href="#contact">연락처</a>
    </nav>
  </header>

  <main>
    <section id="about">
      <h2>나를 소개합니다</h2>
      <p>웹 개발을 배우고 있습니다.</p>
    </section>

    <section id="contact">
      <h2>연락처</h2>
      <a href="mailto:hello@example.com">이메일 보내기</a>
    </section>
  </main>

  <footer>
    <p>만든 사람: 홍길동</p>
  </footer>

  <script src="script.js"></script>
</body>
03 · BUILD ORDER

이 순서대로 만들면 길을 잃지 않습니다.

처음부터 디자인과 기능을 동시에 만들지 말고, 한 단계가 정상인지 확인한 다음 다음 단계로 넘어가세요.

  1. 01
    목적 정하기

    누구에게 무엇을 보여줄 페이지인지 한 문장으로 적습니다.

  2. 02
    종이에 영역 그리기

    머리말, 본문 구역, 버튼과 바닥글의 위치를 간단히 그립니다.

  3. 03
    HTML로 내용 넣기

    디자인 없이 제목, 문단, 목록과 링크가 올바른 순서로 보이는지 확인합니다.

  4. 04
    CSS로 꾸미기

    큰 화면부터 기본 디자인을 정하고 작은 모바일 화면도 함께 조정합니다.

  5. 05
    JavaScript 기능 넣기

    버튼처럼 사용자의 동작이 필요한 부분에만 기능을 추가합니다.

  6. 06
    다시 확인하기

    링크, 글자 잘림, 오타와 모바일 화면을 확인한 뒤 완성합니다.
