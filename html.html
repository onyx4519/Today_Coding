01 · MEANING

HTML은 무엇인가요?

HTML은 HyperText Markup Language의 줄임말입니다. 이름은 길지만 핵심은 간단합니다. 브라우저에게 “이 글은 제목이고, 이 부분은 문단이야”라고 알려주는 표시 언어예요.

이것만 기억하세요

HTML = 웹페이지에 들어갈 내용과 순서를 정하는 코드

02 · HOW TO READ TAGS

태그는 상자처럼 생각하세요.

대부분의 HTML 요소는 여는 태그와 닫는 태그가 한 쌍입니다. 두 태그 사이에 실제 내용을 넣습니다.

<h1> 안녕, 웹! </h1>
여는 태그 화면에 보이는 내용 닫는 태그
닫는 태그에는 슬래시가 들어갑니다.

<h1>으로 시작했다면 </h1>으로 닫아야 합니다. 단, <img>와 <input>처럼 닫는 태그가 없는 요소도 있습니다.

03 · DOCUMENT START

HTML 문서의 첫 부분을 읽어봅시다.

이 코드는 화면에 제목이나 문단을 표시하기 전에 문서의 종류, 언어, 글자 인코딩, 모바일 화면, 브라우저 제목과 CSS 파일을 설정합니다.

index.html · 1~9줄 문서 기본 설정
  1. <!doctype html>
  2. <html lang="ko">
  3. <head>
  4. <meta charset="UTF-8">
  5. <meta name="viewport" content="width=device-width, initial-scale=1.0">
  6. <meta name="description" content="코드를 처음 배우는 사람을 위한 웹페이지 제작 안내서">
  7. <title>웹페이지 제작 시작하기</title>
  8. <link rel="stylesheet" href="styles.css">
  9. </head>
01
<!doctype html>

현재 문서가 최신 HTML 형식인 HTML5 문서라는 것을 브라우저에 알립니다. 태그가 아니므로 닫는 태그가 없습니다.

02
<html lang="ko">

HTML 문서 전체를 감싸는 시작 태그입니다. lang="ko"는 기본 언어가 한국어라는 뜻이며, 파일 마지막에는 </html>로 닫습니다.

03
<head>

브라우저와 검색 서비스에 전달할 문서 설정을 담는 영역입니다. 이 안의 내용은 대부분 페이지 본문에 직접 표시되지 않습니다.

04
charset="UTF-8"

한글과 영문을 포함한 다양한 문자를 올바르게 표시하도록 문자 인코딩 방식을 지정합니다.

05
name="viewport"

휴대전화에서도 페이지 너비와 확대 비율이 화면에 맞게 표시되도록 설정합니다.

06
name="description"

페이지 내용을 짧게 요약합니다. 검색 결과나 공유 화면에서 페이지 설명으로 사용될 수 있습니다.

07
<title>…</title>

브라우저 탭에 표시되는 페이지 이름을 작성합니다. 페이지마다 내용을 구분할 수 있는 제목을 사용합니다.

08
<link rel="stylesheet" …>

현재 HTML 문서와 styles.css 파일을 연결합니다. href에는 CSS 파일의 위치를 적습니다.

09
</head>

<head> 설정 영역을 닫습니다. 그다음에 화면에 보이는 내용을 담는 <body>…</body>를 작성합니다.

<head>와 <body>를 구분하세요.

<head>에는 페이지 설정을, <body>에는 제목·문단·이미지·버튼처럼 화면에 보일 내용을 넣습니다.

04 · COMMON TAGS

웹페이지에서 자주 사용하는 태그

처음부터 모든 태그를 외울 필요는 없습니다. 태그 위에 마우스를 올리면 자세한 사용법과 올바른 예시 구조가 나타납니다. 모바일에서는 태그를 눌러 확인할 수 있습니다.

01
PAGE STRUCTURE

페이지 구조

페이지나 구역의 머리말을 만듭니다.
메뉴와 주요 이동 링크를 묶습니다.
페이지의 핵심 내용을 감쌉니다.
주제가 같은 내용을 하나의 구역으로 나눕니다.
저작권이나 추가 링크가 있는 바닥글을 만듭니다.
02
TEXT

제목과 글

<h1>…</h1>부터 <h6>…</h6>까지 중요도에 따라 제목을 만듭니다.
하나의 문단을 작성합니다.
문장에서 중요한 내용을 강조합니다.
문장 안에서 줄을 한 번 바꿉니다. 닫는 태그 없음
서로 다른 주제 사이를 구분하는 선을 만듭니다. 닫는 태그 없음
03
LINKS & LISTS

링크와 목록

다른 페이지나 외부 사이트로 이동하는 링크를 만듭니다.
순서가 중요하지 않은 글머리표 목록을 만듭니다.
1, 2, 3처럼 순서가 있는 목록을 만듭니다.
<ul>이나 <ol> 안의 각 항목을 만듭니다.
04
MEDIA & ACTION

이미지와 동작

이미지를 표시합니다. src와 alt 속성을 함께 사용합니다. 닫는 태그 없음
사용자가 누를 수 있는 버튼을 만듭니다.
입력칸이 무엇을 입력하는 곳인지 설명합니다.
이름이나 검색어 등을 입력받는 칸을 만듭니다. 닫는 태그 없음

구조 예시

태그는 역할에 맞게 조립합니다.

태그의 이름만 봐도 어떤 내용이 들어 있는지 알 수 있게 작성하면 코드가 읽기 쉬워집니다.

05 · FIRST CODE

첫 HTML 코드를 읽어봅시다.

아래 코드는 머리말, 본문 구역, 목록, 버튼과 바닥글을 가진 간단한 자기소개 페이지입니다. 강조된 한국어를 직접 바꾼 뒤 실행해 보세요.

index.html 
<header class="profile-header">
  <h1>나의 첫 웹페이지</h1>
  <p>웹 개발을 배우고 있습니다.</p>
</header>

<main class="profile-main">
  <section>
    <h2>좋아하는 것</h2>
    <ul>
      <li>3D 프린팅</li>
      <li>로봇 제어</li>
    </ul>
    <button>더 알아보기</button>
  </section>
</main>

<footer>
  <p>만든 사람: 홍길동</p>
</footer>

06 · WRITE IT YOURSELF

직접 태그와 내용을 작성해 봅시다.

아래 다섯 가지는 작성 방법을 보여주는 예시입니다. 원하는 HTML 태그만 골라 자유롭게 작성하면 입력한 코드의 결과를 확인할 수 있습니다.

작성 예시
  1. <h1>원하는 제목</h1>예: 나의 첫 웹페이지
  2. <h2>원하는 소제목</h2>예: 내가 좋아하는 것
  3. <p>원하는 설명</p>예: HTML을 배우고 있어요.
  4. <a href="연결 주소">원하는 링크 글자</a>예: <a href="about.html">소개 보기</a>
  5. <button>원하는 버튼 글자</button>예: 시작하기
주의사항

아래 결과 화면에는 내용을 읽기 쉽도록 글꼴, 여백, 줄 간격, 이미지 크기 등을 정하는 임의의 기본 CSS가 적용되어 있습니다. 따라서 같은 HTML 코드를 새 파일에서 실행했을 때 브라우저의 기본 모양과 다르게 보일 수 있습니다.
