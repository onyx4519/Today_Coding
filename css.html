02 · CONNECT

HTML과 CSS를 먼저 연결합니다.

CSS 파일을 만들어도 HTML에 연결하지 않으면 디자인이 나타나지 않습니다. 두 파일을 같은 폴더에 만들고 HTML의 <head> 안에 아래 한 줄을 작성하세요.

my-page/
├─ index.html
└─ styles.css
index.html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
link외부 파일 연결

HTML에서 다른 파일을 불러올 때 사용하는 태그입니다.

rel="stylesheet"CSS 파일임을 표시

연결할 파일이 스타일시트라는 뜻입니다.

href="styles.css"파일 위치 지정

같은 폴더에 있는 styles.css를 찾아 연결합니다.

가장 먼저 확인할 것

스타일이 나타나지 않으면 파일 이름의 대소문자, 확장자와 폴더 위치가 정확한지 확인하세요.

03 · RULE

CSS 규칙을 한 부분씩 읽어봅시다.

CSS는 “어떤 요소를” 선택하고 “무엇을 어떻게 바꿀지” 작성합니다. 중괄호 안에는 여러 속성을 한 줄씩 넣을 수 있습니다.

.card {
  background: #171727;
  border-radius: 24px;
}
.card선택자

꾸밀 HTML 요소를 선택합니다.

{ }중괄호

적용할 디자인 규칙의 시작과 끝입니다.

background속성

배경색처럼 바꾸고 싶은 항목입니다.

#171727값

속성을 어떤 모습으로 바꿀지 정합니다.

:콜론

속성과 값을 구분합니다.

;세미콜론

하나의 CSS 명령이 끝났음을 표시합니다.

작성 습관

속성 하나를 한 줄에 작성하고 마지막에 세미콜론을 붙이면 코드를 읽고 오류를 찾기 쉽습니다.

COMMENTCSS 주석 작성하기

/*로 시작하고 */로 끝냅니다. 주석 안의 내용은 디자인에 적용되지 않습니다.

/* 카드의 배경과 여백을 꾸밉니다. */
.card {
  background: #171727;
  padding: 24px;
}
04 · SELECTOR

무엇을 꾸밀지 선택하는 방법입니다.

선택자는 HTML 태그의 이름, class, id 등을 이용합니다. 처음에는 태그 선택자와 클래스 선택자를 중심으로 사용하세요.

p
태그 선택자

페이지에 있는 모든 <p></p> 문단을 선택합니다.

예: p { color: gray; }
.card
클래스 선택자

class="card"가 작성된 요소를 선택합니다. 이름 앞에 점을 붙입니다.

예: .card { padding: 24px; }
#intro
아이디 선택자

id="intro"인 하나의 요소를 선택합니다. 이름 앞에 #을 붙입니다.

예: #intro { background: black; }
.card h3
내부 요소 선택자

class="card" 안에 있는 <h3></h3>만 선택합니다.

예: .card h3 { font-size: 28px; }
점과 #을 빠뜨리지 마세요

HTML에는 class="card"라고 작성하지만 CSS에서는 .card라고 작성합니다. id="intro"는 CSS에서 #intro로 작성합니다.

06 · BOX MODEL

모든 HTML 요소는 네 겹의 상자입니다.

버튼, 문단과 카드 같은 요소는 내용, 안쪽 여백, 테두리, 바깥쪽 여백으로 구성됩니다. 이를 박스 모델(Box Model, 요소의 크기와 여백을 계산하는 구조)이라고 합니다.

margin · 다른 요소와의 바깥 간격
border · 테두리
padding · 내용과 테두리 사이
content · 글자와 이미지
margin: 20px;상자 바깥에 공간을 만듭니다.

다른 요소와 너무 붙어 있을 때 사용합니다.

padding: 20px;상자 안쪽에 공간을 만듭니다.

글자와 테두리가 너무 붙어 있을 때 사용합니다.

07 · UNIT & COLOR

값에는 크기 단위와 색상 표현을 사용합니다.

같은 속성도 어떤 값을 넣느냐에 따라 결과가 달라집니다. 처음에는 px, %와 색상 코드부터 사용해도 충분합니다.

크기 단위

px

고정된 크기를 정할 때 사용합니다. 예: font-size: 16px;

크기 단위

%

부모 요소를 기준으로 비율을 정합니다. 예: width: 100%;

크기 단위

rem

기본 글자 크기를 기준으로 계산합니다. 반응형 글자에 자주 사용합니다.

색상

#7650e6

16진수 색상 코드입니다. 여섯 자리로 원하는 색을 표현합니다.

색상

rgb(118, 80, 230)

빨강, 초록, 파랑의 양으로 색을 표현합니다.

색상

rgba(0, 0, 0, .3)

RGB 색상에 투명도를 추가합니다. 마지막 값은 0부터 1까지입니다.

08 · LAYOUT

여러 요소를 가로로 배치해 봅시다.

기본 HTML 요소는 위에서 아래로 놓이는 경우가 많습니다. 부모 요소에 display: flex;를 적용하면 자식 요소를 한 줄로 정렬할 수 있습니다.

.list {
  display: flex;
  gap: 12px;
  justify-content: center;
  flex-wrap: wrap;
}
HTMLCSSJavaScript
display: flex자식 요소를 한 방향으로 배치

기본 방향은 왼쪽에서 오른쪽입니다.

gap: 12px자식 요소 사이의 간격

각 요소에 여백을 따로 주지 않아도 됩니다.

justify-content: center가로 방향 정렬

여기서는 요소들을 가운데로 모읍니다.

flex-wrap: wrap좁은 화면에서 줄바꿈

모바일 화면에서 요소가 밖으로 넘치는 것을 줄입니다.

09 · HOVER

마우스를 올렸을 때 모습을 바꿀 수 있습니다.

:hover는 사용자가 마우스 커서를 요소 위에 올린 상태를 선택합니다. transition을 함께 사용하면 변화가 부드럽게 보입니다.

button {
  transition: 0.2s;
}

button:hover {
  transform: translateY(-2px);
}
마우스를 올려보세요
모바일에는 마우스 커서가 없습니다

:hover 효과가 없어도 버튼의 글자와 기능을 알아볼 수 있도록 기본 상태를 먼저 완성해야 합니다.
