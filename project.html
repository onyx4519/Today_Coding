HTML로 내용을 만들고, CSS로 꾸민 다음, JavaScript로 버튼 기능을 추가합니다. 각 단계가 끝날 때마다 브라우저에서 결과를 확인하세요.

프로젝트 진행 순서 01 파일 준비 02 HTML 작성 03 CSS 적용 04 기능 추가 05 모바일 대응 06 최종 확인
PROJECT GOAL

이름, 소개, 관심 분야와 버튼이 있는 자기소개 페이지

  • 예상 시간: 2~3시간
  • 필요 파일: HTML, CSS, JavaScript
  • 완성 기준: PC·모바일 표시와 버튼 작동
01 · SETUP

프로젝트 폴더와 파일을 만듭니다.

VS Code에서 새 폴더를 연 다음 아래 세 파일을 만드세요. 세 파일의 이름과 위치가 같아야 HTML에서 CSS와 JavaScript를 올바르게 연결할 수 있습니다.

my-profile-page/
├─ index.html
├─ styles.css
└─ script.js
이 단계의 완료 기준

세 파일이 VS Code 왼쪽 파일 목록에 보이고, index.html을 브라우저에서 열 수 있습니다.

02 · WRITE HTML

HTML로 페이지의 내용과 순서를 만듭니다.

아래 코드를 index.html에 작성하세요. 이름, 소개 문장, 관심 분야와 이메일 주소는 자신의 내용으로 바꿔도 됩니다.

index.html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>홍길동의 소개 페이지</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header class="profile-header">
    <nav>
      <a href="#about">소개</a>
      <a href="#favorites">관심 분야</a>
      <a href="#contact">연락처</a>
    </nav>
    <p class="eyebrow">MY FIRST WEBPAGE</p>
    <h1>안녕하세요, 홍길동입니다.</h1>
    <p>웹 개발을 배우고 있는 학생입니다.</p>
  </header>

  <main>
    <section id="about">
      <h2>나를 소개합니다</h2>
      <p>새로운 기술을 직접 만들고 실험하는 것을 좋아합니다.</p>
    </section>

    <section id="favorites">
      <h2>관심 분야</h2>
      <ul>
        <li>웹 개발</li>
        <li>3D 프린팅</li>
        <li>로봇 제어</li>
      </ul>
    </section>

    <section id="contact">
      <h2>연락처</h2>
      <p><a href="mailto:hello@example.com">이메일 보내기</a></p>
      <button id="helloButton" type="button">인사하기</button>
      <p id="helloMessage" aria-live="polite"></p>
    </section>
  </main>

  <footer>
    <p>© 2026 홍길동의 첫 웹페이지</p>
  </footer>

  <script src="script.js"></script>
</body>
</html>
브라우저에서 확인할 것

제목, 세 개의 메뉴, 소개·관심 분야·연락처 구역과 버튼이 순서대로 보여야 합니다.

03 · ADD CSS

CSS로 간격과 색상, 카드 모양을 적용합니다.

아래 코드를 styles.css에 작성하세요. 먼저 전체 구조가 적용되는지 확인한 다음 색상값을 자신이 원하는 색으로 바꿔보세요.

index.html과 styles.css가 같은 폴더에 있는지, href="styles.css"의 철자가 같은지 확인하세요.

04 · ADD JAVASCRIPT

버튼을 누르면 인사말이 나오게 만듭니다.

아래 코드를 script.js에 작성하세요. HTML의 id와 JavaScript에서 찾는 이름이 정확히 같아야 합니다.

script.js
const helloButton = document.querySelector("#helloButton");
const helloMessage = document.querySelector("#helloMessage");

helloButton.addEventListener("click", () => {
  helloMessage.textContent = "방문해 주셔서 감사합니다!";
});
버튼이 작동하지 않을 때

<script src="script.js"></script>가 </body> 바로 위에 있는지, 두 id의 철자가 같은지 확인하세요.

05 · MOBILE

작은 화면에서는 제목과 메뉴를 줄입니다.

아래 코드를 styles.css의 가장 아래에 추가하세요. 화면 너비가 600px 이하일 때만 적용됩니다.

styles.css · 마지막 줄
@media (max-width: 600px) {
  .profile-header {
    padding: 30px 16px 55px;
  }

  nav {
    flex-wrap: wrap;
    gap: 12px;
    margin-bottom: 50px;
  }

  h1 {
    font-size: 34px;
  }

  main {
    width: min(100% - 28px, 720px);
    padding: 45px 0;
  }

  section {
    padding: 22px;
  }
}
모바일에서는 실제 휴대전화에서도 확인하세요.

가로 스크롤이 생기지 않는지, 메뉴와 버튼을 손가락으로 누르기 쉬운지, 제목이 잘리지 않는지 확인합니다.
